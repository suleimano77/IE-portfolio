# Excel

Weeks 1 and 2 of the plan. Each workbook is one step, in order.

| Workbook | What's in it |
| --- | --- |
| [week01-formulas-practice.xlsx](week01-formulas-practice.xlsx) | My first day on Excel: learning formulas and practising IF. A 12×12 multiplication table built from one formula (`=$A2*B$1`), SUM, AVERAGE, ROUND and COUNTIF on it, then a grade sheet with nested IF, IFS and AND/OR. |
| [week01-lookups-pivots.xlsx](week01-lookups-pivots.xlsx) | Joining an orders list to product and supplier lists with XLOOKUP, working out revenue, then summarising it with pivot tables. The data is invented for practice. |
| [week01-problem-set.xlsx](week01-problem-set.xlsx) | Five worked problems, one tab each: compound interest, depreciation, break-even, time study and inventory ordering. Every answer is calculated from coloured input cells, so changing an input updates the results. The problems are invented for practice, not real coursework. |

GitHub can't preview `.xlsx` files. Use **Download raw file** on a workbook's page to open it in Excel.
