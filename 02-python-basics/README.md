# Python basics

Weeks 3 to 4 of the plan. Small programs of my own that use what each CS50P lecture teaches. CS50's own problem sets are done on cs50.dev and are not posted here, as the course asks.

| Program | What it does |
| --- | --- |
| [week03/takt.py](week03/takt.py) | Asks for the minutes in a shift and the units ordered, then prints the takt time: how often one unit has to be finished to keep up with orders. |
| [week03/station_check.py](week03/station_check.py) | Compares a station's cycle time to takt time and says whether it is a bottleneck, tight (under 10% spare time) or fine. |

Run a program from the repo folder, for example `python 02-python-basics/week03/takt.py`.
